# Paolo Roncaglioni — Portfolio

Personal portfolio website built with [Astro](https://astro.build/) and [Tailwind CSS v4](https://tailwindcss.com/).

Live at: [roncax.github.io/portfolio](https://roncax.github.io/portfolio)

## Tech Stack

- **Astro** — static site generator
- **Tailwind CSS v4** — utility-first CSS
- **TypeScript** — type-safe configuration

## Local Development

```bash
npm install
npm run dev
```

## Configuration

All content (bio, skills, experience, education, social links) is managed in a single file:

```
src/config.ts
```

## Deployment

Automatically deployed to GitHub Pages via GitHub Actions on every push to `master`.
